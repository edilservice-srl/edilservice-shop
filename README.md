# EDILSERVICE Shop

Sito di vendita online di EDILSERVICE srl (Magliano Sabina).

- `index.html`: il sito (catalogo, ricerca, carrello, ordine via WhatsApp/email)
- `data.json`: articoli disponibili, generato dal CSV di magazzino LibertyCommerce
- `img/c/`: foto dei prodotti Cardinale Ferramenta, scaricate in automatico da GitHub Actions
- `tools/scarica_immagini.py`: script che abbina il codice fornitore Cardinale alla foto (prime 5 cifre del codice)
